A file system organizes digital storage into files. Windows uses the New Technology File System (NTFS).

# Directory Structure

The root directory is `drive:`. Physical and virtual drives are identified by drive letters.

| **Directory** | **Description** |
| --- | --- |
| `PerfLogs` | Windows performance logs; disabled by default. |
| `ProgramData` | Hidden folder containing data for installed programs. |
| `Program Files` | Installed programs. |
| `Program Files (x86)` | 32-bit programs on 64-bit systems. |
| `Users` | Personal folders for users who have logged on. |
| `Windows` | Operating system installation. |
