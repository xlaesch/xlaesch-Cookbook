
Data structure that maintains the order of digital storage, where a unit is a file. Windows uses New Technology File System (NTFS)


# Directory Structure

The root directory is "drive:". Physical and virtual drives are named by a drive letter. 

- `PerfLogs` is created to keep Windows performance logs, disabled by default.
- `ProgramData` hidden folder that holds data belonging to the programs installed in the system
- `Program Files` folder that holds all the programs installed in the system.
- `Program Files(x86)` folder for 64-bit systems that holds programs installed as 32-bit.
- `Users` contains personal folder for each logged on user.
- `Windows` where the entire operating is installed.
