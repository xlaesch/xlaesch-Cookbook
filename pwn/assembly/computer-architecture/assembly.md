

Physical components do not interpret high-level languages , as they essentially only process 1's and 0's. Assembly enables developers to write readable machine instructions, which are then assembled into their machine code equivalent, so that the processor can run them. Machine code is often represented as shellcode, a hex representation of machine code bytes.

Each processor understands a different set of machine instructions and a differerent assembly language. When high-level code is compiled, it is translated into assembly instructions for the processor it is being compiled for, which is then assembled into machine code. There are also exists interpretive languages (Python, Bash, PHP) which are interpreted during run time. These use libraries to run their instructions so when we issue a command in an interpreted language it uses the compiled library to run that command. 

> A interesting distinction with Java is that it is compiled into a Java Bytecode which is the saem for all processors and is then compiled to machine code by the local Java runtime environment.
