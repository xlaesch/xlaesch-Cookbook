# WHOIS

WHOIS is a query and response protocol designed to access databases that store information about registered internet resources.

Usually reveals names, email addresses, and phone numbers of individuals responsible for managing the domain. Can give insight into the network infrastructure. Historical data can also be viewed to see change in ownership, etc.

```shell
whois inlanefreight.com
```
